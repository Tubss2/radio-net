Default keys are F1 to talk (hold it), F2 for the channel wheel, F3 for the previous channel, F4 for the next channel, and F5 to hide or show the overlay. Keys you already changed stay as they are. Keys you never changed switch to these the next time you open the app.

You can set a callsign. Simple mode is a smaller window. You can link a phone as the talk button. The Windows helper is a separate download, not this installer.

The app asks before it downloads an update. The keyboard hook stays off until you accept the privacy note. The installer is unsigned: on the SmartScreen warning choose More info, then Run anyway. SHA256SUMS.txt next to the installer is the checksum of this file.
