You can set a callsign and the key or mouse button you hold to talk. Simple mode is a smaller window. You can link a phone as the talk button. The Windows helper that watches a key while a game is in front is a separate program, not this installer.

The app asks before it downloads an update. The keyboard hook stays off until you accept the privacy note. The installer is still unsigned: on SmartScreen choose More info, then Run anyway. SHA256SUMS.txt is the checksum of this exe.
