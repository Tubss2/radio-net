# Sounds

## Channel tuned

Played when a channel is tuned onto the radio, and from the **Play squelch** button in settings.

**Radio Sign Off / Squelch** by [JovianSounds](https://freesound.org/people/JovianSounds/). [Freesound 524205](https://freesound.org/people/JovianSounds/sounds/524205/).

Licence: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Credited anyway.

The client ships a mono 16-bit edit (`spike/client/src/renderer/src/assets/squelch.wav`). The original is 1.21 s, 24-bit stereo, 44.1 kHz. The audible burst and its decay last about 0.23 s; the rest of the file is digital silence, so that silence is not in the asset. A short fade closes the end. The peak is −9 dBFS so the cue stays comfortable at the default 40% UI volume.
